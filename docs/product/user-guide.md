# CadWeave 使用说明（0.1 验证版）

## 安装与启动

Windows 安装包的预期路径为 `artifacts/desktop/CadWeave-Setup-0.1.0-x64.exe`。需先按当前源码重新构建，再按向导安装；既有 artifacts 可能属于历史版本，不应当作当前构建。构建未做代码签名，Windows 可能显示未知发布者提示；请仅运行可信来源的构建，正式外部分发前应配置签名。安装包随附 Electron 和 Python 运行环境，不需要目标电脑安装 Node/Python/uv。

目录版位于 `artifacts/desktop/win-unpacked/`，必须整体保留，不能只复制其中的 CadWeave.exe。历史上测试过打包版 EXE 及其内置 Worker，但不代表当前源码已重新完成打包验收；尚未在独立干净电脑上完成安装验收。

## 导航与首次连接

侧栏为“工作台 / 连接 / 记录”。当前产品仅支持 SolidWorks 真实会话，不提供演示模式或 Creo 连接。

1. 自行打开 SolidWorks 和模型，再在“连接”中重新发现并连接会话。无原生桌面桥接、无会话或接口不可用时只显示连接提示与诊断，不生成合成模型。
2. 读取活动文档，确认模型路径、配置、作用域及只读原因。工具只附着既有会话，不自动启动 CAD 或修改官方配置。
3. “工作台”默认查看模式。点击表格行内“编辑”进入该文件编辑，行内“新增/删除”针对该文件；顶部批量操作针对勾选文件。界面仅使用文档属性，不再提供配置属性切换。模型必须满足可写条件，所有操作先进入草稿，不立即改变 CAD。顶层装配与零件规则相同，不因文件为SLDASM而禁改；CAD已有未保存修改、原始测试文件保护等原因在行内/详情中说明。

## 保存草稿与真正提交

“保存”与“提交”是两个独立操作：

1. **保存**：将本地变更写入本机 SQLite 草稿库并退出编辑，不调用 CAD 属性写入或保存。无变更时保存会清除该模型上下文的旧草稿。草稿按 CAD、根模型路径和作用域隔离；重新连接或读取相同上下文时尝试恢复。
2. **取消编辑**：恢复上次已保存草稿；尚未保存的修改需确认后丢弃，不修改 CAD 文件。切换连接、重新读取或关闭时也会提示尚未保存的编辑。
3. **提交**：存在已保存且未再修改、无冲突的草稿时才能提交。核对预览中的操作、模型、属性、原值和新值，再点击“确认提交”，才请求真实 CAD 写入并分文档保存。编辑过草稿后需再次“保存”，不能直接提交未保存编辑。
4. **提交后自动重读**：无论提交返回结果还是抛出异常，界面都会尝试重新读取当前作用域。自动重读失败时保持编辑/提交锁定，需先检查 SolidWorks 状态，再手动重新读取；不能自动重复提交未知结果。
5. 成功且已保存的项从草稿移除，未完成项保留。恢复时若当前模型路径、属性存在性、原值或可写条件与草稿不一致，对应项作为冲突**保留在数据库中，但不载入可提交变更**。请先检查“记录”和当前 CAD 属性，再重新编辑、核对并保存；再次保存会更新该上下文的草稿，不能把冲突项当成已经成功写入或自动合并。

## 工作台与属性操作

- 左树：实例结构，独立折叠、递归搜索、定位；点击“显示全部”恢复矩阵。
- 矩阵：集中编辑属性值；勾选模型后可批量赋值或暂存新增/删除。粘贴制表符/换行文本支持矩形赋值，跳过只读/越界单元格。
- 新增属性：仅支持普通文本，须输入有效属性名；同名已有属性不会被覆盖，不支持改类型。新增项尚未提交时再删除，只撤销本地新增。
- 删除属性：只对符合可写条件的已有普通文本属性暂存删除，提交预览可核对其原值；不是把属性值清空。
- 详情：点击模型名或详情按钮，查看路径、配置、作用域及限制。

## 持久记录与日志导出

“记录”从本机 SQLite 读取，不限于本次界面会话。列表按时间倒序分页，每页最多 200 条，可用“上一页 / 下一页”翻阅。展开写回记录可查看模型路径、属性名、操作（修改/新增/删除）、原值、新值、逐项成功及文件保存状态；列表显示操作时间。

真正提交前，桌面主进程必须先持久保存“待执行/待确认”的审计记录，成功后才允许向 Worker 发送写入请求；结果返回后再更新记录。存储失败会阻止此次 CAD 写入请求；但 CAD 已运行后的审计更新失败不能反推为 CAD 保存失败。异常或中断可能留下待确认/未知记录，需人工检查 CAD，不自动重放。

“导出日志”生成可读的 `.log` 文本，包含操作上下文和逐项变更，不是旧版 JSON 报告，也不是 Excel 往返导入。导出请求覆盖全部历史，而非仅当前页；为控制大小，最多导出 100000 条且受 16 MiB 记录内容预算限制。超过限制时日志头明确标注截断和导出数量，不应把截断日志当作完整历史。

## SolidWorks 支持范围与认证限制

- 仅精确 revision `34.0.0` 开放写回；其他版本默认禁写。只允许已加载、非 dirty、非只读、非原始受保护测试文件的模型，在 `document` 作用域操作。`configuration` 属性仍只读。
- 已在本机实际附着并读取活动装配及已加载子模型；轻量化、抑制、未加载组件不自动解析。已有属性修改/删除仅限未链接普通文本，表达式及非文本等限制会禁止操作；新增仅支持普通文本。
- **实机认证仅覆盖单零件工作副本的既有文本属性修改、Save3 与关闭重开一致性。新增/删除虽已实现，但仅经过 fake COM 逻辑测试，尚未获得真实 CAD 写回及关闭重开认证。不要据此用于未经独立验证的生产新增/删除。**
- 完整装配分文档/子件分组写回只有逻辑测试；实机尝试因同名原装配复用被安全阻断，尚未完成真实端到端认证。生产结果不声明 `verified:true`，提交后重读也不等同于关闭重开认证。

## 安全提示

不要为测试而保存原始业务模型；先制作完整工作副本并确认实际加载路径。多文档 CAD 保存不具备数据库事务保证，SQLite 草稿/审计事务不能回滚 CAD；部分写入、保存失败或结果未知时，应先在 SolidWorks 检查，不自动重试。

Excel 导入导出、复杂编号及外部插件热加载仍为后续能力；新增/删除属性已经有本地草稿和 Worker 实现，但没有真实 CAD 认证，不能再归为“完全未实现”，也不能宣传为已认证能力。
