# SolidProps 使用说明（0.1 验证版）

## 安装与启动

Windows 安装包的预期路径为 `artifacts/desktop/SolidProps-Setup-0.1.0-x64.exe`。需先按当前源码重新构建，再按向导安装；既有 artifacts 可能属于历史版本，不应当作当前构建。支持 Windows 10 / Windows 11 64 位，安装器会拒绝 Windows 7 / 8 / 8.1 和 32 位系统。构建未做代码签名，Windows 可能显示未知发布者提示；请仅运行可信来源的构建，正式外部分发前应配置签名。安装包随附 Electron 和 Python 运行环境，不需要目标电脑安装 Node/Python/uv。

目录版位于 `artifacts/desktop/win-unpacked/`，必须整体保留，不能只复制其中的 SolidProps.exe。历史上测试过打包版 EXE 及其内置 Worker，但不代表当前源码已重新完成打包验收；尚未在独立干净电脑上完成安装验收。

## 导航与首次连接

侧栏为“工作台 / 连接”。当前产品仅支持 SolidWorks 真实会话，不提供演示模式或 Creo 连接。

1. 自行打开 SolidWorks 和模型，再在“连接”中重新发现并连接会话。无原生桌面桥接、无会话或接口不可用时只显示连接提示与诊断，不生成合成模型。
2. 读取活动文档，确认模型路径、配置、作用域及只读原因。工具只附着既有会话，不自动启动 CAD 或修改官方配置。
3. “工作台”默认只读，左侧默认按文件展示，可切换装配结构。点击顶栏“编辑”才能修改、新增或删除；操作对象始终为左侧选中文件。右侧纵向显示属性名和值，单选编辑单文件，多选批量编辑。界面仅使用文档属性。顶层装配与零件规则相同，不因文件为 SLDASM 而禁改；CAD 未保存修改、只读或原始文件保护原因独立显示。开发阶段使用根目录 `pnpm dev`，不自动打包 EXE。

## 保存草稿与真正提交

“保存”与“提交”是两个独立操作：

1. **保存**：将本地变更写入本机 SQLite 草稿库并退出编辑，不调用 CAD 属性写入或保存。无变更时保存会清除该模型上下文的旧草稿。草稿按 CAD、根模型路径和作用域隔离；重新连接或读取相同上下文时尝试恢复。
2. **取消编辑**：恢复上次已保存草稿；尚未保存的修改需确认后丢弃，不修改 CAD 文件。切换连接、重新读取或关闭时也会提示尚未保存的编辑。
3. **提交**：存在已保存且未再修改、无冲突的草稿时才能提交。核对预览中的操作、模型、属性、原值和新值，再点击“确认提交”，才请求真实 CAD 写入并分文档保存。编辑过草稿后需再次“保存”，不能直接提交未保存编辑。
4. **提交后自动重读**：无论提交返回结果还是抛出异常，界面都会尝试重新读取当前作用域。自动重读失败时保持编辑/提交锁定，需先检查 SolidWorks 状态，再手动重新读取；不能自动重复提交未知结果。
5. 成功且已保存的项从草稿移除，未完成项保留。恢复时若当前模型路径、属性存在性、原值或可写条件与草稿不一致，对应项作为冲突**保留在数据库中，但不载入可提交变更**。请先检查当前 CAD 属性，再重新编辑、核对并保存；再次保存会更新该上下文的草稿，不能把冲突项当成已经成功写入或自动合并。

## 工作台与属性操作

- 文件侧栏：根文件优先，同一模型文件只显示一次；同名不同路径保留独立项，重复引用显示次数。点名称单选，勾选框多选；全选只影响当前可见文件，查询不会清除隐藏选择，并提示隐藏的已选文件。
- 装配结构：查看实例层级，点击实例只高亮该实例，并选择其引用文件；切换视图本身不改选择或草稿，批量选择在文件视图完成。
- 属性列表：以所选文件已有属性和这些文件的本地新增属性的并集为准，不使用未勾选文件或第一个文件作为模板；“仅共同属性”限制为所选文件均存在的属性。多文件显示同值或“多个不同值”，并标注覆盖文件数。查看态是纯文本，不提供可聚焦输入框；进入编辑后可写值立即出现边框。属性查询按名称和值过滤，不改变选择。状态统一为“待提交”，具体新增/修改/删除类型可从悬停或提交预览核对；底栏另区分编辑未保存与已保存待提交。
- 批量编辑：弹窗预览目标和跳过原因；缺少属性默认跳过，只有明确选“修改已有属性，并为缺少的文件新增”才补建。多个不同值不会默认被空值覆盖，必须输入新值或明确点击清空按钮。清空属性值与不修改不同。
- 新增属性：表格下方内联新增，按选中文件应用，仅支持普通文本；已有同名属性跳过不覆盖，大小写变体不补建。待新增项删除只撤销本地新增。
- 删除属性：勾选属性行后删除，预览数量；缺少属性跳过，待删除项保留显示，可撤销。删除只在提交后真正执行。
- 右键：复制名称/值、修改、新增、删除、撤销，修改类功能必须先进入全局编辑，且不改变文件选择。
- 保存范围是整个工作台的本地变更，提交范围是全部已保存变更，与查询过滤和当前勾选无关；确认窗口逐项列出文件、属性及原/新值。工作流程固定为“编辑 → 保存 → 提交”。

## 持久记录与日志导出

“记录”从本机 SQLite 读取，不限于本次界面会话。列表按时间倒序分页，每页最多 200 条，可用“上一页 / 下一页”翻阅。展开写回记录可查看模型路径、属性名、操作（修改/新增/删除）、原值、新值、逐项成功及文件保存状态；列表显示操作时间。

真正提交前，桌面主进程必须先持久保存“待执行/待确认”的审计记录，成功后才允许向 Worker 发送写入请求；结果返回后再更新记录。存储失败会阻止此次 CAD 写入请求；但 CAD 已运行后的审计更新失败不能反推为 CAD 保存失败。异常或中断可能留下待确认/未知记录，需人工检查 CAD，不自动重放。

“导出日志”生成可读的 `.log` 文本，包含操作上下文和逐项变更，不是旧版 JSON 报告，也不是 Excel 往返导入。导出请求覆盖全部历史，而非仅当前页；为控制大小，最多导出 100000 条且受 16 MiB 记录内容预算限制。超过限制时日志头明确标注截断和导出数量，不应把截断日志当作完整历史。

## SolidWorks 支持范围与认证限制

- 仅认证 revision `34.0.0` 开放写回；其他版本默认禁写并显示只读原因。SolidWorks 2018（`26.0.0`）以下直接拒绝连接；2018–2025 按 Get6 设计可读取，但未逐版本实机认证。只允许已加载、非 dirty、非只读、非原始受保护测试文件的模型，在 `document` 作用域操作。`configuration` 属性仍只读。
- 已在本机实际附着并读取活动装配及已加载子模型；轻量化、抑制、未加载组件不自动解析。已有属性修改/删除仅限未链接普通文本，表达式及非文本等限制会禁止操作；新增仅支持普通文本。
- **实机认证仅覆盖单零件工作副本的既有文本属性修改、Save3 与关闭重开一致性。新增/删除虽已实现，但仅经过 fake COM 逻辑测试，尚未获得真实 CAD 写回及关闭重开认证。不要据此用于未经独立验证的生产新增/删除。**
- 完整装配分文档/子件分组写回只有逻辑测试；实机尝试因同名原装配复用被安全阻断，尚未完成真实端到端认证。生产结果不声明 `verified:true`，提交后重读也不等同于关闭重开认证。

## 安全提示

不要为测试而保存原始业务模型；先制作完整工作副本并确认实际加载路径。多文档 CAD 保存不具备数据库事务保证，SQLite 草稿/审计事务不能回滚 CAD；部分写入、保存失败或结果未知时，应先在 SolidWorks 检查，不自动重试。

Excel 导入导出、复杂编号及外部插件热加载仍为后续能力；新增/删除属性已经有本地草稿和 Worker 实现，但没有真实 CAD 认证，不能再归为“完全未实现”，也不能宣传为已认证能力。
