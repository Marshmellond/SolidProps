# CadWeave 使用说明（0.1 验证版）

## 安装与启动

Windows 安装包的预期路径为 `artifacts/desktop/CadWeave-Setup-0.1.0-x64.exe`。需先按当前源码重新构建，再按向导安装；既有 artifacts 可能属于历史版本，不应当作当前 SolidWorks-only 构建。构建未做代码签名，Windows 可能显示未知发布者提示；请仅运行可信来源的构建，正式外部分发前应配置签名。安装包随附 Electron 和 Python 运行环境，不需要目标电脑安装 Node/Python/uv。

目录版位于 `artifacts/desktop/win-unpacked/`，必须整体保留，不能只复制其中的 CadWeave.exe。历史上测试过打包版 EXE 及其内置 Worker，但不代表当前源码已重新完成打包验收；尚未在独立干净电脑上完成安装验收。

## 首次连接与编辑

当前产品仅支持 SolidWorks 真实会话，不提供演示模式或 Creo 连接。

1. 自行打开 SolidWorks 和模型，再在连接管理重新发现并连接会话。无原生桌面桥接、无会话或接口不可用时只显示连接提示与诊断，不生成合成模型。
2. 读取活动文档，确认路径、配置和只读原因。工具只附着既有会话，不自动启动 CAD 或修改官方配置。
3. 默认查看模式，点击右上角“编辑属性”进入编辑；没有可写属性时按钮禁用。仅在下述认证范围内修改现有属性，修改单元格为琥珀色。编辑期间勾选模型后可批量赋值或应用模板；粘贴制表符/换行文本支持矩形赋值，跳过只读/越界单元格。
4. 点击“保存”，检查原值与新值，再点击“确认写入并保存”才会实际写回 CAD。无变更不能保存。“取消编辑”只丢弃本地草稿，有修改时需确认，不会保存 CAD 文件。
5. 全部成功后退出编辑；部分失败保留失败项草稿。任何提交尝试后需重新读取快照才能继续编辑，避免不明确状态下重复提交。保存结果未知时先在 SolidWorks 中检查，不自动重试。

## SolidWorks 支持范围

- SolidWorks：已在本机34.0.0实际附着并读取活动装配及已加载子模型；轻量化/抑制/未加载组件不自动解析。34.0.0支持非dirty/非只读模型的document既有普通文本分文档保存；单零件Save3已在副本重开认证，完整装配分组写回只有逻辑测试，实机因同名原装配复用被安全阻断，尚未完成真实端到端认证。配置属性当前只读，其他版本默认禁写。开发原始测试文件受保护，需完整工作副本。

模型已有未保存修改、只读、表达式/非文本等限制会禁用编辑。不要为测试而保存原始业务模型；先制作完整工作副本并确认实际加载路径。

## 工作区

- 左树：实例结构，独立折叠、递归搜索、定位；点击“显示全部”恢复矩阵。
- 矩阵：唯一编辑目标，既有属性编辑。v1暂不支持新增/删除属性和改类型。
- 详情：点击模型名或详情按钮，查看路径、配置、作用域及限制。
- 模板：从选中或首个模型保存属性值，应用时仅修改已有可写字段，不会新增属性。
- 记录：本次界面会话的真实操作，可导出JSON报告；不是永久审计数据库。
- 设置：紧凑行高、只读显示、路径显示，保存在本机。

## 安全提示

多文档保存不具备数据库事务保证。写入、保存、重读核对是不同结果，重读不等于关闭重开验证。保存状态未知时不要重复提交；先在CAD检查。

当前导出为JSON操作报告，不等于Excel往返导入。Excel导入导出、新增删除属性、复杂编号及外部插件热加载为后续功能，界面不会用虚假按钮冒充已实现。
