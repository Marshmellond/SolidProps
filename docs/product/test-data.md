# 测试数据与安全边界

2026-10-29 将外层 `测试文件/` 移入 CadWeave 项目根目录，共593个文件，移动前后逐文件 SHA256 一致。此目录默认被Git忽略，不上传远程。

当前 SolidWorks 测试候选为活塞总成。历史资产中其他 CAD 模型仅保留为客户本地文件，不表示当前产品可发现、读取或修改它们；当前不提供 Creo 运行时。实际层级、依赖和版本以 SolidWorks 实际加载为准，不能按无序号文件或最高数字后缀直接断言版本正确。

任何真实写入测试必须复制完整依赖到 `.local/` 工作目录，再确认CAD实际加载路径。不得在原始 `测试文件/` 中保存测试改动；不得自动启动并保存用户当前文档。真实集成测试无法完成时，记录未验证，禁止用假 COM、合成数据或历史演示结果替代；当前产品不提供演示模式。
