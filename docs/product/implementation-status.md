# 实现状态与验收纪律

## 当前产品范围

- 当前运行时只注册 SolidWorks 驱动，只附着用户已打开的真实会话；没有演示模式、合成模型或 Creo 发现/连接/参数读取。
- 界面导航为“工作台 / 连接 / 记录 / 属性模板 / 偏好设置”。界面与协议保留通用 CAD 身份、模型、发生项、作用域和能力描述；Worker 通过通用适配器协议及显式插件注册保留未来扩展点，不表示其他 CAD 已交付。
- 无可连接会话或原生桌面桥接时明确显示连接提示，不自动启动 CAD、修改用户环境或回退到合成数据。

## 草稿、提交与记录

- “保存”只持久化本机 SQLite 草稿并退出编辑；不写 CAD、不保存 CAD 文件。“提交”需要已保存且未修改、无冲突的非空草稿，并经预览确认才调用真实写回。
- 草稿按 CAD、根模型路径和作用域隔离，通过模型路径重新匹配当前快照。冲突项保留在数据库，但不会载入可提交列表，也不会自动合并、重试或当作成功。重新编辑保存会更新该上下文草稿。
- 取消编辑恢复上次草稿；未保存变更需确认后丢弃。提交后，无论正常返回或发生异常都会尝试自动重读；重读失败保持刷新锁，不能继续编辑/提交。
- 桌面主进程必须在请求 Worker 写入前持久提交 pending 审计记录；存储不可用时拒绝发送写入。CAD 返回后记录逐项结果；请求异常记录 unknown，审计完成更新失败保留 pending 并提示，不把已经执行的 CAD 操作误报为未执行。
- 记录持久化至本机 SQLite，显示时间，支持展开模型路径、属性、操作、原值、新值和逐项写入/保存状态，每页最多 200 条。`.log` 导出请求包含全部历史而非当前页；受 100000 条及 16 MiB 记录内容预算限制，超限在文件头显式标注截断及数量。不是 Excel 往返能力，也不是不可篡改的外部合规审计系统。

## 属性 CRUD 与兼容边界

- 变更协议可选 `operation` 为 `update` / `add` / `delete`，省略时兼容既有更新。矩阵、草稿、预览、审计与 Worker 支持三种操作；新增仅支持普通文本。模板应用仍只更新已有可写字段，不自动创建缺失属性。
- SolidWorks 真实写回仍仅精确 revision `34.0.0` 的已加载根/子模型 `document` 作用域；configuration 只读，其他版本禁写。dirty、只读、原始受保护测试文件、未加载组件及不支持的属性条件仍会阻止写入；已有属性修改/删除仅限未链接普通文本。
- **新增/删除的实现与 fake COM 测试不是实机认证。真实 CAD 的 Add3/Delete2 写回、保存及关闭重开一致性尚未认证。**
- 单零件工作副本的既有文本属性修改与 Save3 关闭重开已认证；完整装配子件分组保存未完成实机认证，生产结果 `verified:false`。界面提交后自动重读不是关闭重开验证，多文档保存也不具有数据库事务或自动回滚保证。

## 验收原则

假 COM 和合成测试数据只证明协调器、界面或协议逻辑，不证明任意厂商版本互操作，也不构成产品演示模式。真实写回若因 API 绑定或环境未认证而禁用，必须在连接能力、只读原因和文档中一致呈现。不得把旧测试数量或旧演示成功写成本轮真实模型验证成功；以最新实际输出和兼容性边界为准。本轮最终自动化数量由完成最新测试的执行者汇总，文档维护不得沿用或推测中途数量。
