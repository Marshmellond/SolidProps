# 实现状态与验收纪律

## 当前产品范围

- 当前运行时只注册 SolidWorks 驱动，只附着用户已打开的真实会话；没有演示模式、合成模型或 Creo 发现/连接/参数读取。
- 界面与协议保留通用 CAD 身份、模型、发生项、作用域和能力描述；Worker 通过通用适配器协议及显式插件注册保留未来扩展点，不表示其他 CAD 已交付。
- 无可连接会话或原生桌面桥接时明确显示连接提示，不自动启动 CAD、修改用户环境或回退到合成数据。
- SolidWorks 写回仍仅精确 revision `34.0.0` 的已加载根/子模型 document 作用域既有未链接文本属性；configuration 只读，其他版本禁写。单零件副本 Save3 已认证，完整装配子件分组保存未完成实机认证，生产结果 `verified:false`。

以下为此前开发阶段记录，不是本轮重新检测或验收结果：原始测试目录593文件迁移前后 SHA256 一致；曾发现 SolidWorks 可执行文件版本34.0.0.5070。安装文件存在不等于 API 连通，历史安装包与测试记录不代表当前源码已重新构建验收。

## 验收原则

假 COM 和合成测试数据只证明协调器、界面或协议逻辑，不证明任意厂商版本互操作，也不构成产品演示模式。真实写回若因 API 绑定或环境未认证而禁用，必须在连接能力、只读原因和文档中一致呈现。不得把旧测试数量或旧演示成功写成本轮真实模型验证成功；以最新实际输出和兼容性边界为准。
