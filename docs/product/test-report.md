# 自动化与实机测试记录

历史记录日期：2026-10-29。以下数量、旧演示流程与旧安装包结果仅描述当时版本，不是本轮验证结果，也不表示当前仍包含 Creo 或演示功能。当前产品仅连接真实 SolidWorks；本轮产品收敛后的检查结果由实际执行者另行报告，不沿用旧数量。

## 本轮变更与验证边界

本轮涉及简体中文导航、本机 SQLite 草稿与持久记录、保存/提交分离、提交后自动重读（含异常路径）、冲突草稿隔离、写入前 pending 审计、逐项历史详情、分页与 `.log` 全历史导出，以及可选 `operation: update/add/delete` 的属性 CRUD。新增仅支持普通文本，省略 operation 仍表示更新；模板不自动创建属性。

- 测试重点包括草稿恢复及原值/属性存在性冲突、冲突项保留但不载入提交、已保存草稿提交门禁、提交失败仍重读、存储失败阻止 CAD 写入、审计异常状态、历史分页及导出截断提示，以及新增/删除的 fake COM 协调与保存结果处理。
- 最新回归：Python 128 项、桌面 Vitest 33 项通过；TypeScript 类型检查、生产构建、Worker 冻结及 NSIS 安装包构建通过。独立测试数据库验证打包 Worker 的草稿跨进程保存/读取及日志导出通过，未连接 CAD。未运行本轮 Electron 端到端或视觉验收，未进行新增/删除实机写回认证。
- 新增/删除实际 CAD 写回及关闭重开**未认证**；fake COM 测试通过只说明逻辑，不等于 Add3/Delete2 实机成功。单零件既有文本更新的历史 Save3 认证不自动扩展到新增/删除或完整装配。
- revision 必须精确为 `34.0.0`，configuration 只读等写入边界保持不变。生产重读不是关闭重开认证，`verified:false` 不应改为已认证。
- 本次文档整理未运行测试、未启动 CAD、未连接/修改/保存真实模型，也未重新验收安装包。
