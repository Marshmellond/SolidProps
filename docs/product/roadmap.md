# 功能路线与未完成范围

## 当前迭代

当前产品聚焦红灰桌面界面、真实 SolidWorks 父子属性读取和认证范围内安全写回。运行时仅注册 SolidWorks，不提供演示模式；保留可扩展 Worker 契约，其他 CAD 驱动不在当前交付范围。安装包与自动化测试须按当前源码重新验收，历史结果不替代本轮验证。

## 下一优先级

1. SolidWorks 实机认证：完成完整装配工作副本的子件分组保存验证；现有单零件副本 Save3 认证不等于完整装配端到端通过。未来其他 CAD 需独立立项，确认目标产品、官方 SDK 与授权，经显式插件注册和独立认证后再声明支持。
2. SolidWorks：扩大已验证版本矩阵、配置属性写回、轻量化组件用户授权解析、更多属性类型。
3. Excel：包含稳定目标身份和原值快照的导出/导入预览与冲突检查；不是按文件名盲写。
4. 大装配：虚拟化矩阵与树、分页/分批读取、取消未执行任务。当前原生表格适合功能验证，不承诺万级节点性能。
5. 长期审计与规则：持久化历史、属性新增/删除、字段模板与复杂编号、正式备份管理。
6. 外部分发：代码签名、干净机器安装验收、目标CAD版本回归和依赖安全审计。

## 不混淆的概念

假 COM 或合成数据测试≠真实 CAD 写回；Save API 返回成功≠重开验证；API 组件已安装≠已注册且能连接；Electron 打包成功≠任意版本 CAD 兼容；通用扩展契约≠已交付其他 CAD 驱动。
