# 安全与分发检查

- Renderer启用contextIsolation与sandbox，nodeIntegration=false。preload仅暴露白名单请求、经用户文件对话框授权的导出、窗口控制。
- 主进程拒绝外部窗口与导航；不将任意命令/路径作为Worker写盘入口。
- Worker版本化协议，拒绝未知字段、重复JSON键、请求ID重放、过大请求、跨快照目标、原值冲突及未知属性。
- 原值/模型身份校验不是跨进程事务锁；CAD用户操作可能并发变化，必须逐项复核，失败停止。
- 安装包未签名，正式分发需代码签名与干净机器验收。
- 依赖安全审计尝试未完成：本机npmmirror注册源无audit端点，官方npm端点访问又失败；不得声称依赖无漏洞。开发使用Electron35进行初始验证，正式发布前应升级到受维护且经过回归的版本并完成漏洞审计。
