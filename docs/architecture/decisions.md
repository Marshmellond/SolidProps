# 架构决策

## ADR-001：桌面与CAD SDK分离

使用Electron/React/TS进行交互，独立Python Worker串行调用CAD。无需目标用户安装Python/Node。SDK可随CAD使用不同语言，不强制未来中望驱动使用Python。

## ADR-002：本地stdio而非HTTP

v1无本地服务端口，协议每行JSON，stdout与日志分离。Electron主进程仅允许白名单方法，渲染层不能任意执行命令、读取磁盘或传入写盘路径。

## ADR-003：保守能力与实机认证

未知版本只读而非猜测可写。SolidWorks34.0.0普通文本Save3绑定已在独立单零件副本重开验证，完整装配子件分组保存尚未完成实机认证，生产保存不重开且 verified=false。当前仅提供 SolidWorks 真实会话；无会话或接口不可用时明确诊断，不自动修改注册表，不生成演示数据。

## ADR-004：安全优先于假事务

写回整批预检，快照一次消费，状态不明锁定连接。多文档保存不具事务回滚；UI必须逐项展示保存和核对状态。

## ADR-005：测试资产不进源码历史

593原始模型移入项目但Git忽略；副本放.local，哈希核对并仅对副本保存。远程由用户自行配置推送。

## ADR-006：视觉与交互基线

用户指定浅灰shell与红色品牌；白色矩阵为中心，不依赖暗色导航。无会话时显示真实连接提示，保存状态不能用本地dirty代替。主题通过CSS集中维护。

## ADR-007：单一产品运行时与通用扩展分离

当前产品仅注册 SolidWorks，不保留 Creo 或演示运行时。通用 CadAdapter/CadPlugin 契约与显式注册表保留；发现和适配器工厂共享注册信息，未知 CAD 拒绝连接。未来驱动须独立实现、授权检查与认证后显式纳入，不自动加载任意外部代码。
