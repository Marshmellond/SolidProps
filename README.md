# SolidProps

SolidProps 是一款面向 SolidWorks 用户的文档属性管理工具。它连接本机已打开的 SolidWorks 会话，把装配体及其子零件的自定义属性集中到一个界面中查看和编辑，减少逐个打开模型修改属性的重复操作。

## 主要功能

- **集中查看**：一次读取当前文档的装配树与所有模型属性，按文件切换查看。
- **批量编辑**：在一个工作台内修改多个模型的普通文本属性，支持撤销、重做和撤回全部。
- **保存与写回分离**：编辑先保存为本地草稿，确认预览后才写回 CAD。
- **写回可追踪**：提交前记录审计信息，写回后自动重新读取，避免把未知状态当成成功。
- **装配结构只读浏览**：查看父子层级、实例名称和引用关系，不修改装配结构。
- **版本与兼容提示**：连接时识别 SolidWorks 版本，不支持写回的版本会明确提示只读原因。

## 系统要求

- Windows 10 或 Windows 11（64 位）
- 已安装 SolidWorks，并已启动、打开目标文档
- SolidWorks 2018 及以上可读取属性
- 写回目前支持 SolidWorks 2026；其他版本以只读方式使用

## 下载与安装

前往 [GitHub Releases](https://github.com/Marshmellond/SolidProps/releases) 下载最新安装包：

```text
SolidProps-Setup-<版本>-x64.exe
```

安装按当前用户进行，无需管理员权限。安装包未签名时，Windows SmartScreen 可能提示“未知发布者”；请核对 Release 中提供的 SHA256 后再运行。

## 使用流程

1. 启动 SolidWorks 并打开要处理的装配体或零件。
2. 打开 SolidProps，在「连接」页选择检测到的 SolidWorks 会话并连接。
3. 在「工作台」选择文件，查看或编辑属性。
4. 编辑完成后点击「保存」保存草稿，再点击「提交」查看变更预览。
5. 确认无误后提交，SolidProps 会写回 CAD 并自动重新读取结果。

> 「保存」只保存本地草稿，不会修改 CAD 文件；只有「提交」才会写回。

## 数据与安全

- 仅连接本机已经运行的 SolidWorks，不启动隐藏实例，也不修改 CAD 私有文件格式。
- 写回前先记录审计信息；写回后自动重读，失败或状态不明时会保留草稿并提示。
- 草稿和日志保存在 `%APPDATA%\SolidProps`，不写入安装目录。
- 默认只处理普通文本属性；链接属性、配置特定属性和装配结构不会被修改。
- 新增/删除属性功能仍在完善中，当前建议以修改已有属性为主。

## 常见问题

**没有检测到 SolidWorks 会话**

先启动 SolidWorks 并打开文档，再回到「连接」页刷新。

**属性显示为只读**

可能是 SolidWorks 版本不在写回支持范围内，或当前文档只读、存在未保存修改、被其他操作占用。界面会显示具体原因。

**写回后提示重新读取失败**

请先检查 SolidWorks 中的文档状态，再手动重新连接或刷新；不要重复提交同一批修改。

**如何卸载**

在 Windows「设置 → 应用 → 已安装的应用」中找到 SolidProps 卸载，或运行安装目录中的卸载程序。
